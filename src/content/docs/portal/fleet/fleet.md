## La liste des box

La page **Mes box** est l'accueil du portail. Elle liste toutes les box auxquelles vous avez accès.

![Liste des box](./devices.png)

En haut, quatre compteurs résument le parc : **Total**, **Online** (en ligne), **Offline** (hors ligne) et **Alarmes**.

Pour chaque box :

- **État** : en ligne si la box a donné des nouvelles dans l'heure, sinon hors ligne ;
- **Nom** et **projet** éventuel ;
- **Alarmes** actives ;
- **Réseau** et **Accès** ;
- **Dernier contact**.

Le champ de recherche et le filtre **Tous les projets** (ou les box sans projet) réduisent la liste. Cliquez sur une box pour ouvrir sa [fiche](/portal/fleet/device/).

## La carte

La page **Carte** place les box sur une carte, à partir de l'adresse ou des coordonnées renseignées. Les box d'un même [projet](/portal/dashboards/dashboards/#les-projets) partagent un seul repère, avec la synthèse de leurs box ; les box sans projet ont chacune le leur.
