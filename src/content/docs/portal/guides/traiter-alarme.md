---
title: Être prévenu et traiter une alarme
description: "Recevoir les alarmes sur son téléphone, retrouver ce qui se passe et comprendre qui est prévenu."
sidebar:
  order: 5
---

1. **Sur votre téléphone** : installez l'application ([Application sur téléphone](/portal/getting-started/mobile/)) puis, dans la page **Alarmes**, **Activer** les notifications sur cet appareil.
2. **Voir ce qui se passe** : le compteur **à traiter** de l'en-tête ouvre les alarmes. **Fil de l'eau** montre les alarmes en cours ; une alarme du jour déjà terminée y figure marquée **provisoire** jusqu'à l'arrivée du rapport journalier.
3. **Comprendre** : cliquez sur la box ou ouvrez l'onglet **Alarmes** de son projet ; les **Signalements** donnent ce que les techniciens ont déclaré sur place (photos comprises).
4. **Régler qui est prévenu** : **Administration ▸ Destinataires ▸ Alertes** : pour chaque box, les personnes, les canaux (mail, SMS, appel) et l'escalade ([Destinataires d'alarme](/portal/alarms/alarm-recipients/)).

Un **Opérateur** (ou plus) peut acquitter les alarmes ; un **Lecteur** les consulte seulement.
