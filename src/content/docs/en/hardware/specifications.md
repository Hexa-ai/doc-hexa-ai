## Core & compute

| | |
| --- | --- |
| Module | Raspberry Pi CM4 quad-core, 4 GB RAM |
| Storage | 32 GB soldered eMMC, optional 128 GB industrial micro-SD (historisation switches over automatically) |
| System | Debian 12 · HAI-OS, web administration interface |

## Connectivity

| | |
| --- | --- |
| Wired network | Two Ethernet ports, separately configurable, no routing between them by default |
| Serial ports | 4 on the terminal block — 2× RS232 + 2× RS485 |
| Wireless & remote | 4G LTE + Wi-Fi, built-in Tailscale, automatic link failover |

## Ruggedness

| | |
| --- | --- |
| Form factor | Aluminium enclosure, DIN rail mounting |
| Power | Industrial terminal block, wide DC range |
| Reliability | Real-time clock, service monitoring and automatic restart |
